A basic and simplicistic clone of Tetris made in JS.

## How it works
The blocks are drawn on a JS Canvas. 
The pieces are numbers stored in a 2d Array.
The falling piece or player is stored as an object and manipulated over time.
## Controls
← → Move |
↓ Drop |
R Rotate |
Space Hard Drop |
P Pause |
ESC Restart
